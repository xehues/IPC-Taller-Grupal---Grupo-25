# Ensamblaje

Unión de lecturas secuanciadas solapadas para la reconstrucción de secuencias genómicas más largas.

**Programas usados:** FastQC (revisar calidad), Trimmomatic (eliminar adaptadores y bases de baja calidad), SPAdes (ensabla lecturas para reconstruir genomas) y QUAST (evaluar la calidad del ensamblaje obtenido).

**Salida:** Archivos limpios en `data/processed_data/` e informes en `results/`.
