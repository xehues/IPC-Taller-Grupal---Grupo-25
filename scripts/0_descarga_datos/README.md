# Descarga de datos

**1. Clona el repositorio:** en tu máquina local.

**2. Crea y activa el entorno** con las herramientas necesarias.

**3. Ejectua** 0_descarga_datos.sh

**Al terminar:** `data/raw/` contendrá los FASTQ comprimidos de cada muestra SRRxxx_R1.fastq.gz y SRRxxx_R2.fastq.gz (2 porque son PAIRED)
